# Contributing to LoQS

Thanks for taking the time to contribute to LoQS! Open-source projects like
ours couldn't exist without contributors like you.

These are guidelines for contributing to LoQS and related packages hosted
under the [SandiaLabs][sandialabs] organization. Please make an earnest effort
to follow them, but no one's keeping score -- use your best judgement, and
feel free to propose changes to this document in a pull request.

- [Reporting bugs and suggesting features](#reporting-bugs-and-suggesting-features)
- [Making a contribution](#making-a-contribution)
- [Use of generative AI tools](#use-of-generative-ai-tools)

## Reporting bugs and suggesting features

Found a bug, or want to add or change a feature? We'd appreciate hearing
about it!

1. **Check whether it's already been reported** by searching the
   [issue tracker][issues].
   - Also check closed issues in an open [milestone][milestones]. These are
     fixed but not yet released, so the fix is either on `main` or in a
     release branch that will ship soon.
2. **If you can't find one, [open a new issue][issues:new].** There are two
   issue forms:
   - **Single bug or feature request** asks for a short **summary**, a
     **minimal working example** (a code block or an attached notebook) if
     you can, and the **outcome you expected** or want.
   - **Multiple related bugs** groups several bugs in one issue, with a
     checklist and a section per bug.
3. **Keep an eye on the issue** once it's open -- you may be asked for more
   details.

## Making a contribution

Want to fix a bug, add a feature, or change an existing one? Open a pull
request against `main`. The pull request template asks for a summary, where
reviewers should focus, and how you tested the change.

Because LoQS is a project of Sandia National Laboratories, the process
differs for contributors working at Sandia.

### For non-Sandians

Include a sentence in your pull request stating that your contributions are
made under the terms of the [Apache License, Version 2.0][license], the
license LoQS is distributed under. For example:

> These contributions are being made under the terms of the open-source
> Apache 2.0 license.

If you have questions, you can reach the authors at [loqs@sandia.gov][email].

### For Sandians

1. **Join the [SandiaLabs][sandialabs] organization.**
2. **Contact the authors** at [loqs@sandia.gov][email] to request an invite
   to the [repository][repo].

## Use of generative AI tools

If your contribution was developed with the help of generative AI tools
(agentic or otherwise), please:

- **Say so and name the model(s) used.** Annotating your commit messages with
  this is best practice. If your commits already exist, a note in the pull
  request is also fine. Please don't put these annotations in the source code
  itself.
- **Attest that you have thoroughly reviewed** all contributions written with
  generative AI tools.
